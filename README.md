# PAC-MAN: Neon Maze

Классическая аркада на Python 3.11+ и Pygame: соберите все точки, избегайте
четырёх призраков и используйте энергетические шарики, чтобы дать отпор.
Лабиринт создаётся процедурно и меняется на каждом уровне.

## Установка и запуск

```powershell
cd C:\Users\user\pacman_game
python -m pip install -r requirements.txt
python main.py
```

Управление: **WASD** или **стрелки**; **P / Esc** — пауза. Окно можно менять
в размере. На экране настроек доступна регулировка громкости; звуки и фоновая
мелодия синтезируются средствами Pygame. При недоступном аудиоустройстве игра
продолжает работать без звука.

Рекорд и громкость сохраняются в JSON-файлах внутри `data/`.

## Модули

- `main.py`, `game.py` — точка входа, игровой цикл, состояния, сохранения.
- `maze.py`, `ai.py` — уровни, поиск пути A* и стратегии четырёх призраков.
- `player.py`, `ghost.py` — движение и отрисовка персонажей.
- `menu.py`, `audio.py`, `settings.py` — экраны интерфейса, звук и параметры.
